# Segunda etapa de oportunidades — plan de implementación

> **For agentic workers:** ejecutar con executing-plans en esta sesión, con revisión independiente mediante requesting-code-review antes de publicar. El usuario aprobó implementación; las entrevistas y la elección de negocio quedan diferidas hasta revisar el domingo.

**Goal:** conservar evidencia útil, distinguir repetición real de recapturas y mejorar cobertura mexicana sin pagos ni trabajo manual del usuario.

**Architecture:** funciones puras de calidad, contexto y cronología; conectores acotados dentro del trabajo actual; informes y API existentes. Esquema JSON aditivo, sin cambios de cartera ni pantallas nuevas.

**Tech Stack:** Next16/React19, TypeScript, PostgreSQL/Drizzle, Vitest/Playwright y CKAN público. Guía instalada de Route Handlers revisada. Sin nuevas dependencias ni API generativa.
